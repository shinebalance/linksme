### セットアップ

```bash
npm install
npm run dev
```

### ビルド

```bash
npm run build
```

`content/profile.md`, `content/links.md`, `content/seo.md` は厳格に検証されます。
形式エラーや必須キー不足がある場合はビルド失敗します。

### Markdown形式

- `content/profile.md`

	```md
	# 表示名
	タグライン（任意）
	![avatar](/avatar-light.svg)  # 任意
	```

- `content/links.md`

	```md
	- [YouTube](https://example.com) {id=youtube icon=youtube}
	```

	- `id` は一意必須
	- URL は `https://` のみ

- `content/seo.md`

	```md
	title: shineloops | links
	description: ...
	ogImage: /ogp.svg
	ogUrl: https://linksme.pages.dev/
	```

### 実装メモ

- リンクは新規タブで開きます
- テーマは `localStorage` 優先、未設定時はOS設定に追従します
- リンクごとにURLコピー機能があります
- SEOメタは `seo.md` からビルド時に `index.html` へ注入されます

### Cloudflare Pages デプロイ設定

Cloudflare Pages のプロジェクト作成時は以下を設定してください。

- Framework preset: `Vite`
- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: `/`
- Environment variable: `NODE_VERSION=20`

このリポジトリには `wrangler.toml` を追加済みです。

```toml
pages_build_output_dir = "dist"
```

補足:

- デプロイ後に確定した公開URLを `content/seo.md` の `ogUrl` へ反映してください。
- GA4の測定ID (`G-XXXXXXXXXX`) は、発行後に `index.html` へ設定してください。
